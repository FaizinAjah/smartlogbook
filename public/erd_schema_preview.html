Dokumentasi Hari 1 (Senin)

Entity Relationship Diagram (ERD) & Perancangan Skema Database

Struktur Relasi Antara Institusi, Dosen/Guru Pembimbing, Peserta Magang, dan Akun Pengguna

Database Engine

MySQL 8.0 / Drizzle ORM

institutions TABLE
PK id bigint unsigned
name varchar(255)
address text
phone varchar(50)
email varchar(255)
created_at, deleted_at
mentors TABLE
PK id bigint unsigned
FK institution_id bigint unsigned
FK user_id bigint unsigned
name varchar(255)
nip / identity varchar(100)
phone, email varchar
created_at, deleted_at
interns TABLE
PK id bigint unsigned
FK user_id bigint unsigned
FK institution_id bigint unsigned
FK mentor_id bigint unsigned
school_major varchar(255)
status varchar(50)
start_date, end_date
users AUTH
PK id bigint unsigned
name varchar(255)
email varchar(255)
access_type tinyint (1,2,3)
is_active tinyint
Role: 1=Admin, 2=Siswa, 3=Pembimbing
institutions → mentors : 1-to-Many (1 institusi memiliki banyak pembimbing)
mentors → interns : 1-to-Many (1 pembimbing membimbing banyak peserta magang)
users → mentors/interns : 1-to-1 (Akun login terintegrasi otomatis)
